# 22. `Box`, `Rc`, `Deref` и `Drop`

> ⏱ **~50 минут** · теория 20 мин · практика 30 мин

Умный указатель — это структура, которая ведёт себя как ссылка, но владеет данными и делает что-то сверх простого указывания. Вы уже пользовались двумя: `String` и `Vec<T>` — тоже умные указатели. Разберём три остальных, которые нужны постоянно, и два трейта, делающих их «умными».

## `Box<T>` — значение в куче

Самый простой умный указатель: кладёт данные в кучу, оставляя на стеке только указатель.

```rust
let b = Box::new(5);
println!("b = {b}, b+1 = {}", *b + 1);
```

Ради одного числа так делать незачем — `Box` нужен в трёх ситуациях.

**Рекурсивные типы.** Размер типа должен быть известен при компиляции, а рекурсивная структура определяется через саму себя:

```rust
// ❌ не компилируется
enum List {
    Cons(i32, List),
    Nil,
}
```

```
error[E0072]: recursive type `List` has infinite size
  |
1 | enum List { Cons(i32, List), Nil }
  | ^^^^^^^^^             ---- recursive without indirection
  |
help: insert some indirection (e.g., a `Box`, `Rc`, or `&`) to break the cycle
  |
1 | enum List { Cons(i32, Box<List>), Nil }
```

Компилятор пытался посчитать размер и ушёл в бесконечность. `Box` разрывает цепочку: его размер всегда один указатель, независимо от содержимого.

```rust
let list = Cons(1, Box::new(Cons(2, Box::new(Nil))));
```

Так устроены деревья, списки и любые структуры со ссылками на себя.

**Объекты-трейты.** `Box<dyn Trait>` из статьи 16 — тот же приём: размер конкретного типа неизвестен, размер указателя известен всегда.

**Передача больших данных.** Перемещение владения копирует значение на стеке. Если структура большая, дешевле переместить `Box` — то есть один указатель.

## `Deref` — почему `Box` ведёт себя как ссылка

Трейт `Deref` определяет поведение оператора `*`. Напишем свой аналог `Box`:

```rust
struct MyBox<T>(T);

impl<T> Deref for MyBox<T> {
    type Target = T;
    fn deref(&self) -> &T {
        &self.0
    }
}
```

Теперь `*my_box` работает. Но интереснее другое — **автоматическое разыменование** (deref coercion):

```rust
fn hello(name: &str) { println!("привет, {name}"); }

let m = MyBox::new(String::from("Rust"));
hello(&m);          // &MyBox<String> → &String → &str
```

Функция ждёт `&str`, а получила `&MyBox<String>`. Компилятор сам применил `deref` дважды, пока не подошёл тип. Без этого пришлось бы писать `hello(&(*m)[..])`.

Именно так `&String` превращается в `&str` — то самое «бесплатное преобразование» из статьи 8. И по той же причине методы `String` доступны у `Vec<String>`-элементов, а методы среза — у вектора.

## `Drop` — уборка при выходе

Трейт с одним методом, который вызывается **автоматически**, когда значение выходит из области видимости:

```rust
struct Resource { name: String }

impl Drop for Resource {
    fn drop(&mut self) {
        println!("освобождаю {}", self.name);
    }
}
```

```
внутри блока
освобождаю B
после блока
освобождаю A
```

Два наблюдения. Во-первых, `B` освободился на закрывающей скобке блока — ровно то самое третье правило владения из статьи 6. Во-вторых, значения освобождаются **в порядке, обратном созданию**.

`Drop` — это то, чем в Rust заменяют `finally` и деструкторы: закрытие файлов, разрыв соединений, освобождение блокировок. Вызвать `drop` вручную нельзя (иначе освобождение случилось бы дважды), но можно передать значение в функцию `std::mem::drop`, чтобы освободить раньше срока.

## `Rc<T>` — разделяемое владение

Правило «владелец ровно один» иногда мешает: узел графа принадлежит нескольким рёбрам, элемент интерфейса — нескольким контейнерам. Для таких случаев есть `Rc` — счётчик ссылок (reference counting).

```rust
use std::rc::Rc;

let rc = Rc::new(String::from("общие данные"));
println!("{}", Rc::strong_count(&rc));      // 1

let rc2 = Rc::clone(&rc);
println!("{}", Rc::strong_count(&rc));      // 2

{
    let _rc3 = Rc::clone(&rc);
    println!("{}", Rc::strong_count(&rc));  // 3
}
println!("{}", Rc::strong_count(&rc));      // 2
```

`Rc::clone` **не копирует данные** — он лишь увеличивает счётчик. Это дёшево, и писать его принято именно так, а не `rc.clone()`: в коде сразу видно, что копирования данных не происходит.

Когда счётчик доходит до нуля, данные освобождаются. Обратите внимание, как счётчик сам уменьшился на выходе из блока — это работает `Drop`.

Два ограничения, о которых надо помнить:

- **`Rc` даёт только чтение.** Изменять содержимое через него нельзя — иначе нарушилось бы правило заимствования. Обход — в следующей статье.
- **`Rc` не потокобезопасен.** Счётчик обновляется без синхронизации. Для нескольких потоков есть `Arc` (статья 25).

## Что запомнить

- Умный указатель владеет данными и делает что-то сверх указывания; `String` и `Vec` — тоже умные указатели.
- `Box<T>` кладёт значение в кучу: нужен для рекурсивных типов, объектов-трейтов и передачи больших данных.
- Рекурсивный тип без `Box` не компилируется — размер уходит в бесконечность (`E0072`).
- `Deref` задаёт поведение `*` и включает автоматическое разыменование, благодаря которому `&String` работает как `&str`.
- `Drop` вызывается автоматически при выходе из области видимости; порядок — обратный созданию.
- Вручную `drop` не вызывают, используют `std::mem::drop`.
- `Rc<T>` даёт нескольким владельцам общие данные через счётчик ссылок; `Rc::clone` копирует не данные, а счётчик.
- `Rc` — только чтение и только один поток.

## Практика

**1. Рекурсивный тип.** Опишите бинарное дерево `Tree` с числом в узле и двумя потомками. Сначала без `Box` — разберите `E0072`. Затем почините. Готово, когда собирается дерево из трёх узлов.

**2. Порядок освобождения.** Создайте три структуры с `Drop`, часть в блоке, часть снаружи. **До** запуска предскажите порядок сообщений. Готово, когда предсказание совпало.

**3. Раннее освобождение.** Создайте значение с `Drop` и освободите его до конца функции. Затем попробуйте вызвать `.drop()` напрямую и разберите ошибку. Готово, когда понимаете, почему компилятор это запрещает.

**4. Счётчик ссылок.** Создайте `Rc` и печатайте `strong_count` в пяти точках: после создания, после двух клонов, внутри вложенного блока с третьим клоном и после него. Готово, когда все пять чисел объяснимы.

**5. Своё автоматическое разыменование.** Реализуйте `MyBox<T>` с `Deref`. Напишите функцию, принимающую `&str`, и вызовите её от `MyBox<String>`. Затем уберите реализацию `Deref` и посмотрите на ошибку. Готово, когда можете объяснить, что именно сделал компилятор.
