# 5. Функции, выражения и управление потоком

> ⏱ **~55 минут** · теория 20 мин · практика 35 мин

Последняя статья про базовый синтаксис. Разберём функции, циклы и условия — и главное, поймём разницу между выражением и инструкцией. В Rust она значит куда больше, чем в других языках: от одной точки с запятой зависит, скомпилируется программа или нет.

## Функции

Объявление начинается с `fn`, имена пишут в `snake_case`:

```rust
fn greet(name: &str, age: u8) {
    println!("{name}, вам {age}");
}

fn main() {
    greet("Алия", 30);
}
```

Типы параметров указывать **обязательно** — компилятор их не выводит. Это осознанное решение: сигнатура функции служит документацией и не должна зависеть от того, как её вызвали.

Тип возвращаемого значения пишется после стрелки:

```rust
fn plus_one(x: i32) -> i32 {
    x + 1
}
```

Обратите внимание: `return` нет, а точки с запятой после `x + 1` — тоже. Это не небрежность, а ключевая механика языка.

## Выражения и инструкции

В Rust код состоит из двух вещей.

**Инструкция** (statement) выполняет действие и **не возвращает значения**. Например, `let x = 5;` — инструкция.

**Выражение** (expression) вычисляется **в значение**. `5 + 6`, вызов функции, литерал `7` — всё это выражения.

Точка с запятой превращает выражение в инструкцию, то есть **выбрасывает результат**. Отсюда правило: последнее выражение в теле функции без точки с запятой становится возвращаемым значением.

Посмотрим, что будет, если поставить лишнюю точку с запятой:

```rust
// ❌ не компилируется
fn plus_one(x: i32) -> i32 {
    x + 1;
}
```

```
error[E0308]: mismatched types
 --> f1.rs:1:24
  |
1 | fn plus_one(x: i32) -> i32 {
  |    --------            ^^^ expected `i32`, found `()`
  |    |
  |    implicitly returns `()` as its body has no tail or `return` expression
2 |     x + 1;
  |          - help: remove this semicolon to return this value
```

Компилятор объясняет всё: результат выброшен, функция вернула `()` — тот самый unit из прошлой статьи, — а обещала `i32`. И сразу подсказывает, что убрать.

Ключевое слово `return` в Rust есть, но применяется для **раннего** выхода из функции. Писать его в последней строке не принято.

Блок `{ }` — тоже выражение, и он возвращает значение последней строки:

```rust
let y = {
    let x = 3;
    x * 2
};    // y == 6
```

## Условия

Синтаксис привычный, но с двумя отличиями от C-подобных языков: **условие не заключают в круглые скобки**, и оно обязано быть именно `bool`. Никаких «ноль — это ложь»:

```rust
let number = 7;

if number % 2 == 0 {
    println!("чётное");
} else if number % 3 == 0 {
    println!("делится на три");
} else {
    println!("остальное");
}
```

Раз `if` — выражение, его результат можно присвоить:

```rust
let condition = true;
let number = if condition { 5 } else { 6 };
```

Это заменяет тернарный оператор, которого в Rust нет. Но у ветвей должен быть **общий тип**:

```rust
// ❌ не компилируется
let number = if condition { 5 } else { "six" };
```

```
error[E0308]: `if` and `else` have incompatible types
 --> f2.rs:3:44
  |
3 |     let number = if condition { 5 } else { "six" };
  |                                 -          ^^^^^ expected integer, found `&str`
```

Иначе компилятор не смог бы назвать тип переменной `number` — а он обязан знать его на этапе компиляции.

## Циклы

Циклов три, и каждый решает свою задачу.

**`loop`** — бесконечный, выход только через `break`:

```rust
let mut counter = 0;

let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2;
    }
};
println!("Результат: {result}");   // 20
```

Уникальная возможность: `break` умеет **возвращать значение** из цикла. Удобно, когда операцию нужно повторять до успеха.

**`while`** — цикл с условием:

```rust
let mut n = 3;
while n != 0 {
    println!("{n}!");
    n -= 1;
}
```

**`for`** — перебор элементов. В Rust это основной цикл, им пишут подавляющее большинство перебора:

```rust
let arr = [10, 20, 30];
for value in arr {
    println!("v={value}");
}
```

Для перебора чисел используют диапазоны: `1..4` даёт 1, 2, 3 (правая граница не включена), `1..=4` включает четвёрку. Метод `.rev()` разворачивает диапазон:

```rust
for i in (1..4).rev() {
    println!("{i}");
}
```

```
3
2
1
```

Почему `for` предпочтительнее `while` со счётчиком? Потому что при переборе по индексу легко ошибиться в границе и получить панику или пропустить элемент. `for` эту ошибку делает невозможной.

Из вложенных циклов выходят с помощью **меток**, начинающихся с апострофа:

```rust
'outer: for i in 1..5 {
    for j in 1..5 {
        if i * j > 6 {
            break 'outer;
        }
    }
}
```

Без метки `break` вышел бы только из внутреннего цикла.

## Что запомнить

- Типы параметров и возвращаемого значения функции указываются всегда.
- Выражение вычисляется в значение, инструкция — нет. Точка с запятой выбрасывает результат.
- Последнее выражение функции без точки с запятой — это возвращаемое значение. `return` нужен для раннего выхода.
- Блок `{ }` — тоже выражение и возвращает свою последнюю строку.
- Условие `if` пишется без круглых скобок и обязано быть `bool`.
- `if` — выражение, его можно присвоить, но ветви должны иметь одинаковый тип.
- `loop` умеет возвращать значение через `break значение`; `for` — основной цикл для перебора; из вложенных циклов выходят по метке `'label`.

## Практика

**1. Функция с возвратом.** Напишите функцию `square(x: i32) -> i32`, возвращающую квадрат числа, — без `return` и без точки с запятой в последней строке. Затем поставьте точку с запятой и запишите текст ошибки. Готово, когда вы видели оба состояния и понимаете сообщение.

**2. Чётность через выражение.** Напишите функцию `parity(n: i32) -> &'static str`, которая возвращает `"чётное"` или `"нечётное"`, используя `if` как выражение (одна строка в теле). Готово, когда в теле функции нет ни одного `return`.

**3. Таблица умножения.** С помощью вложенных циклов `for` выведите таблицу умножения от 1 до 9 — по строке на каждое число. Готово, когда вывод читается как настоящая таблица.

**4. Цикл, возвращающий значение.** С помощью `loop` и `break значение` найдите наименьшее число больше 100, которое делится и на 7, и на 11. Результат присвойте переменной и выведите. Готово, когда программа печатает 154.

**5. Метки.** Напишите два вложенных цикла по диапазону 1..=10, которые ищут первую пару чисел с произведением больше 50, печатают её и **полностью** прекращают перебор. Сначала попробуйте без метки и посмотрите, что пойдёт не так. Готово, когда программа печатает ровно одну пару.

4. Когда в Rust уместно писать `return`?
5. Почему у веток `if`, результат которого присваивается переменной, должен быть одинаковый тип?
