# 8. Срезы, `String` и `&str`

> ⏱ **~55 минут** · теория 20 мин · практика 35 мин

Два строковых типа вместо одного — то, что чаще всего сбивает с толку в первые недели. На самом деле путаницы нет: `String` владеет данными, `&str` их одалживает. Разберёмся с этой парой, а заодно со срезами — способом сослаться на **часть** коллекции, не копируя её.

## Срез — это ссылка на кусок

Срез (slice) — ссылка на непрерывный участок коллекции. Синтаксис — диапазон в квадратных скобках:

```rust
let arr = [1, 2, 3, 4, 5];
let part = &arr[1..3];
println!("{part:?} len={}", part.len());
```

```
[2, 3] len=2
```

Тип `part` — `&[i32]`, срез массива целых. Правая граница не включается, как и в диапазонах из статьи 5.

Ключевое: **срез ничего не копирует**. Внутри это указатель на первый элемент и длина. Поэтому передать в функцию срез — операция бесплатная, независимо от размера данных.

Сокращения: `&arr[..3]` — с начала, `&arr[2..]` — до конца, `&arr[..]` — целиком.

Запись `{part:?}` в `println!` — вывод в отладочном формате. Для массивов и срезов обычный `{}` не работает: как именно печатать список, зависит от задачи. Подробно — в статье 17.

## `String` и `&str`

Со строками ровно та же логика, только срез строки имеет собственное имя — `&str`.

**`String`** владеет данными и может расти; содержимое лежит в куче. Создаётся через `String::from(...)` или `.to_string()`.

**`&str`** данными не владеет и расти не может; они лежат где угодно — в бинарнике, в куче, на стеке. Берётся из строкового литерала или как срез `String`.

Строковый литерал `"привет"` — это `&str`. Данные лежат прямо в исполняемом файле, а переменная хранит ссылку на них. Поэтому литерал нельзя изменить: вы им не владеете.

`String` — растущая строка в куче. Ей владеют, её можно менять, она освобождается при выходе владельца из области видимости.

Взять срез строки можно так же, как срез массива:

```rust
let s = String::from("привет мир");
let hello = &s[0..12];
```

Двенадцать, а не шесть — потому что **границы среза задаются в байтах**, а каждая кириллическая буква в UTF-8 занимает два байта. Если промахнуться мимо границы символа, программа упадёт:

```rust
let s = String::from("привет");
let bad = &s[0..3];
```

```
thread 'main' panicked at s2.rs:3:17:
end byte index 3 is not a char boundary; it is inside 'р' (bytes 2..4 of string)
```

Это плата за то, что строки в Rust — честный UTF-8, а не набор однобайтовых символов. Индексировать строку по одному байту (`s[0]`) язык вообще запрещает: слишком легко получить половину символа. Для перебора есть явные методы — `.chars()` для символов и `.bytes()` для байтов.

## Правило: принимайте `&str`, а не `&String`

Практический вывод, который стоит запомнить сразу. Функция, которой нужно только прочитать строку, должна принимать `&str`:

```rust
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }
    s
}
```

Такую функцию можно вызвать и от `String`, и от литерала:

```rust
let s = String::from("привет мир");
println!("{}", first_word(&s));          // привет

let literal = "я строковый литерал";
println!("{}", first_word(literal));     // я
```

Если бы параметр был `&String`, литерал пришлось бы предварительно превращать в `String` — лишнее выделение памяти на ровном месте. Обратное преобразование бесплатно: `&String` автоматически приводится к `&str`.

Правило: **владеющий тип — в возврате и в полях структур, заимствованный — в параметрах**.

## Срез помнит, что он заимствование

Самое ценное свойство срезов — они участвуют в проверках borrow checker. Смотрите:

```rust
// ❌ не компилируется
let mut s = String::from("привет мир");
let word = &s[0..6];
s.clear();
println!("{word}");
```

```
error[E0502]: cannot borrow `s` as mutable because it is also borrowed as immutable
 --> s3.rs:4:5
  |
3 |     let word = &s[0..6];
  |                 - immutable borrow occurs here
4 |     s.clear();
  |     ^^^^^^^^^ mutable borrow occurs here
5 |     println!("{word}");
  |                ---- immutable borrow later used here
```

Метод `clear()` очищает строку, а значит, нуждается в изменяемом заимствовании. Но `word` всё ещё ссылается на её содержимое. Разреши компилятор такое — и `word` указывал бы на освобождённую память.

Сравните с языками, где длина и индексы хранятся отдельными переменными: там очистка строки просто сделает сохранённый индекс бессмысленным, и вы узнаете об этом в проде. Здесь связь между данными и ссылкой на них выражена в системе типов — и проверена при сборке.

## Что запомнить

- Срез — ссылка на часть коллекции: указатель плюс длина, без копирования данных.
- Границы задаются как диапазон `[start..end]`, правая граница не включается.
- `String` владеет данными и может расти; `&str` — заимствованный взгляд на строку.
- Строковый литерал — это `&str`, лежащий в бинарнике.
- Границы строкового среза считаются **в байтах**; попадание в середину UTF-8 символа вызывает панику.
- Функции для чтения строк должны принимать `&str` — так они работают и со `String`, и с литералами.
- Срез — полноценное заимствование: пока он жив, изменять исходные данные нельзя.

## Практика

**1. Срезы массива.** Создайте массив из десяти чисел. Выведите первые три элемента, последние три и середину — используя все три формы сокращённой записи. Готово, когда ни в одном срезе не написано число 10.

**2. Байты против символов.** Возьмите строку `"привет"` и выведите её длину через `.len()`, а затем количество символов через `.chars().count()`. Объясните разницу. Готово, когда можете сказать, почему числа отличаются вдвое.

**3. Ловим границу символа.** Воспроизведите панику `not a char boundary`. Затем найдите такой срез той же строки, который работает корректно. Готово, когда есть оба варианта и понимание, как считаются байты.

**4. Универсальная функция.** Напишите функцию `last_word(s: &str) -> &str`, возвращающую последнее слово строки. Вызовите её от `String` и от литерала — одной и той же функцией. Готово, когда оба вызова работают без преобразований типов.

**5. Срез против изменения.** Воспроизведите ошибку `E0502` со срезом и `clear()`. Затем почините код так, чтобы и срез использовался, и строка очищалась, — не удаляя ни одну из операций. Готово, когда программа печатает слово, а потом очищает строку.
